# 🚀 HiveMind AI

> Learn software engineering through AI-guided project blueprints.

🌐 **Live Demo: ** https://hivemind-ai-five.vercel.app

💻 **Source Code: ** https://github.com/Suunaina/hivemind-ai

## 📖 Overview

HiveMind AI is an AI-powered project learning platform that helps developers transform project ideas into structured, step-by-step implementation blueprints.Using multiple specialized AI agents, it guides users through understanding concepts, learning technologies, building projects, and improving implementations, all within an interactive workspace.

## ✨ Features

- 🤖 AI-powered project blueprint generation
- 📚 Four-stage guided learning workflow (Understand → Learn → Build → Improve)
- 💬 Ask Hive AI Mentor for contextual project guidance
- 🏗️ Interactive architecture diagrams
- 🎯 Personalized learning paths (Beginner, Intermediate, Advanced)
- 📈 Persistent progress tracking across sessions
- 🏆 Achievement and skill progression system
- 🔐 Secure JWT authentication
- 👨‍💼 Role-based Admin Dashboard
- 📱 Fully responsive modern UI with glassmorphism
